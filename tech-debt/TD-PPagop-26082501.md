**Severity:** Low

#771 moved roughly half of `agent-cycle.sh`'s 96 functions out to `lib/*.sh`
(the stage-attempt, Approver, Landing, Enabler, Refiner and candidate-
selection/stand-down seams), across several commits on PR #773. The spec's
own "Components" entries for the functions that moved are updated in that
same PR (agent-cycle.sh's own entry, and `lib/approver.sh`'s, `lib/
refinement.sh`'s and `lib/review-gate.sh`'s), plus new entries for
`lib/standdown.sh`, `lib/candidate-select.sh` and `lib/stage-attempt.sh`, and
the one other direct `(function, agent-cycle.sh)` citation a targeted grep
for the moved functions' names found (`_landing_stage_attempt`, in the
Landing Gate section).

That grep was scoped to the exact functions moved by #773's own commits, not
exhaustive across the whole 17,758-line document — a spec this size can cite
a function's old location in prose without the literal
`` `fn`, `agent-cycle.sh` `` pairing the grep matched (e.g. "agent-cycle.sh's
own X", a citation split across two sentences, or one naming a caller rather
than the function itself). Whoever picks this up should re-grep the document
for every function name #771/#773 moved (see PR #773's own commit messages
for the full list) with looser patterns than an exact adjacent-citation
match, and correct anything still describing agent-cycle.sh as the function's
home.

This is expected to grow rather than shrink as #771 continues: further
extractions (the repo-ordering/candidate-gathering loop, and the Co-
Ordinator-through-finishing phase sequence, both still inline in
`agent-cycle.sh` as of #773) will move more of what this document currently
attributes to it. A single sweep once #771 is fully landed will cost less
than one per intermediate PR.

Noticed while working PR #773 (#771).

**Suggested fix:** once #771's split is complete (or at its next significant
milestone), grep the spec for every moved function name and correct any
remaining agent-cycle.sh attribution; consider whether the "Components"
section would benefit from a per-file function index instead of scattering
citations through prose, which is what let this drift happen silently in
the first place.
