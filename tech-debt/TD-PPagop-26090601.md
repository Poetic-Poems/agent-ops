test/drain.test.sh (added in PR #1180) is committed without the executable bit — the sole exception among the ~178 test/*.test.sh files, all mode 100755. Its own header documents direct invocation ('Run directly: ./test/drain.test.sh'), which fails with 'Permission denied'. Nothing operational is affected: .github/workflows/build-image.yml and scripts/run-tests.sh both invoke tests as `bash "$t"`, and the suite passes. Fix: `git update-index --chmod=+x test/drain.test.sh` (or chmod +x and commit), restoring the repo-wide convention so the documented invocation works.

## Default: chmod +x and commit the mode change, matching every other test file's 100755 — rather than rewording the header's usage line, since direct execution is the convention the rest of the suite follows.
Noticed while the Approver was judging https://github.com/Poetic-Poems/agent-ops/pull/1180.
