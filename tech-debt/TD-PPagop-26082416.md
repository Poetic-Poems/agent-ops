**Severity:** Medium

Running the pipeline locally (per README.md / `deploy/docker/README.md`)
requires Docker, a live GitHub token, a configured git identity, Tailscale
for the dashboard, and Claude credentials. The test suite intentionally
runs inside the project's own built image rather than against a mock
(`scripts/run-tests.sh`'s own header explains why). No mocked GitHub API
fixtures exist for exercising pipeline logic without live credentials.

This is proportionate to the project's current single-operator audience —
there has been no second contributor yet to make the gap felt.

**Ongoing cost:** low today; will matter more once `docs/ROADMAP.md`'s
productisation work (D1/D9) brings in contributors who are not the
operator and should not need live write-scoped credentials just to iterate
on pipeline logic.

**Suggested fix:** a minimal mocked/fixture-replayed GitHub API path for
exercising at least Co-Ordinator candidate selection and Implementer
dispatch, building on the existing `test/fixtures/` conventions rather than
inventing a new pattern. Not urgent — revisit alongside the roadmap's
contributor-facing work, not before.
